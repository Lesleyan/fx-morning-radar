# FX 晨间雷达

这是用于《外汇交易模拟》课程的静态晨报网页模板，可直接双击打开 `index.html`。

## 每日更新

编辑 `app.js` 中的 `brief` 对象：

1. `quotes`：填入昨晚收盘、今晨开盘和变动；
2. `macro`：更新宏观因子的相对强弱与说明；
3. `usdcad`：更新打分、观点和关键价位；
4. `news`：更新新闻，并在交易日志或附加报告中留存原始新闻链接、数据来源或截图。

页面内为演示数据，来自工作区的 USD/CAD 课程报告中的分析框架，不是实时行情。

## AI 辅助案例写法

把本网页作为报告附件时，单独提交一份《AI辅助外汇交易案例》。建议结构：

1. **AI 使用证据**：放网页截图和关键 AI 对话原文/节选；
2. **交易背景**：货币对、日期、昨收今开、事件与宏观矛盾；
3. **AI 的具体作用**：说明 AI 如何归纳新闻、区分数据水平与预期差、整理宏观因子与关键价位；
4. **独立决策与结果**：明确哪些判断由本人核验、最终是否交易、仓位/止损/止盈及结果；
5. **作用总结与反思**：AI 的效率收益、可能的时效性或幻觉风险，以及如何用原始来源和风控规则约束它。

不要把 AI 输出写成“AI 给出交易指令”。应强调：AI 负责信息整理与提出待验证假设，方向、风险参数和执行均由本人独立决定。
